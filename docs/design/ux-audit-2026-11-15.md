## P2（打磨，收益中等）

- **右栏概览与页头信息重复**：工作区名/路径在页头、左栏项目、右栏概览各出现一次（截图 01）；建议右栏只留「变更 / 摘要」，路径 hover 可见。
- **空态重复**：左栏「暂无会话」+ 中栏「等待任务」+ 右栏「工作区干净」三处空信息；保留中栏主空态，左右栏用一行状态即可。
- **厂商卡端点省略**：`sp-tile-sub` 已带 `title`，但触屏无 hover；可在编辑抽屉里提供可复制端点（已有）之外，卡片上给「本地 / 云端」标签替代长 URL。
- **长会话性能**：对话流已虚拟化，但轨迹未；1000+ 工具调用时先测 DOM 节点与滚动帧率，再决定虚拟化（P0-2 的合并/筛选通常先把规模降下来）。
- **主题/宽度即时生效的可见说明**：常规页宽度滑块实时生效，但没有「已应用」反馈；与 P1-3 合并处理。

## 建议的下一批（按投入产出）

1. **配置可读性**（P0-1 + P1-5）：optionLabels + effective 回显 + 统一三态文案；只动设置模型与渲染层，判据可钉字段表。
2. **轨迹检索**（P0-2）：筛选 + 同工具合并 + 轮次锚点；先不做虚拟化，用真实 139 条会话验收。
3. **键盘与 axe 扩面**（P0-3）：分组头/事件详情语义化，axe 扫真实路由。
4. **设置搜索/深链**（P1-1）与**保存状态**（P1-3）：一套字段索引两处复用（搜索 + 状态）。
5. **移动端收口**（P1-4）：顶栏更多菜单 + 输入区折叠策略。

## 验收口径建议

- 每条改动都补一条可证伪判据（字段表 / 交互 / axe），并在真实 1600×1000 与 390×844 各跑一次；
