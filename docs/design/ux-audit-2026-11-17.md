## 批次 C · i18n

- **真硬编码收口（~37 处）**：掉线授权横幅（5，掉线即见、可见度最高）、决策详情「为什么」
  解释段 + 执行尾（16，模板串化）、会话导出文稿（8，落盘外发内容）、useDecisionLedger（2）、
  决策详情 aria-label（1）。
- **逻辑 bug**：ConsoleUI 用 `hint.includes('重启')` 在 t() **翻译后**的文案上做中文子串判断，
  en 下「需重启」标记静默失效 → 字段新增结构化 `needRestart` 标记（3 个字段），渲染层不再猜文案。
- **en 漂移**：常规栏 hint 改过源码没改词条（旧键成孤儿）→ 同步修复。
- **en 孤儿词条清理**：85 个 key（脚本按「源码全文语料比对」机械判定；教训：跨行条目的
  「续行跳过」若不区分 key 行是否含同行 value，会把下一条目连坐——首轮曾链式误删一段，
  修复后重跑并由 i18nCoverage / 决策 / 控制台判据把关）。
- **死代码**：DialogService 的 DEFAULT_CONFIRM/CANCEL_LABEL 零引用，删除。
- 不动项：GraphTab SAMPLE prompts（示例内容非界面文案）、AppReducers 命令面板（渲染层已 t()）。
